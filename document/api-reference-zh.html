概览

AppleSeed 提供了一套完整的 Hook API，允许其他模组在运行时拦截和覆写核心营养系统的行为。 配合 Type API 进行数据建模，外部模组可以完全自定义食物检测、配方过滤、Tooltip 渲染和营养值计算规则。

所有 API 类均位于 net.appleseed.appleseed.api 包下：

  • api.hook — Hook 接口 + DietHookRegistry（注册/注销/调用）
  • api.query — 查询接口（IDietFoodQuery、DietQuery）
  • api.type — 数据类型接口（IDietGroup、IDietResult 等）
  • api.util — 工具记录类（DietColor）
注册时机： Hook 应在模组初始化期间注册（例如在 @Mod 构造函数中或 FMLCommonSetupEvent 上）。 注册后立即生效，并持续有效直到显式注销。

快速开始

在模组构造函数中注册一个 Hook：

示例 — 最小化 Hook 注册
@Mod("yourmodid")
public class YourMod {
    public YourMod() {
        DietHookRegistry.registerItemFoodEatHook(new IDietItemFoodEatHook() {
            @Override
            public boolean shouldIntercept(Player player, ItemStack stack) {
                return stack.is(Items.GOLDEN_APPLE);
            }

            @Override
            public Map<String, Float> modifyNutritionGains(
                    Player player, ItemStack stack,
                    Map<String, Float> originalGains) {
                originalGains.put("fruits", 0.5f);
                return originalGains;
            }
        });
    }
}

DietHookRegistry

net.appleseed.appleseed.api.hook.DietHookRegistry

所有 Hook 接口的统一注册中心。为每种 Hook 类型提供静态的 register/unregister 方法， 并包含内部静态方法供 AppleSeed 核心调用，按注册顺序依次触发所有已注册的 Hook。

方法描述
registerItemFoodEatHook(IDietItemFoodEatHook)注册物品食物进食 Hook
unregisterItemFoodEatHook(IDietItemFoodEatHook)注销物品食物进食 Hook
registerBlockFoodEatHook(IDietBlockFoodEatHook)注册方块食物进食 Hook
unregisterBlockFoodEatHook(IDietBlockFoodEatHook)注销方块食物进食 Hook
registerRecipeFilterHook(IDietRecipeFilterHook)注册配方过滤 Hook
unregisterRecipeFilterHook(IDietRecipeFilterHook)注销配方过滤 Hook
registerTooltipFilterHook(IDietTooltipFilterHook)注册 Tooltip 过滤 Hook
unregisterTooltipFilterHook(IDietTooltipFilterHook)注销 Tooltip 过滤 Hook
registerNutritionRuleHook(IDietNutritionRuleHook)注册营养值规则 Hook
unregisterNutritionRuleHook(IDietNutritionRuleHook)注销营养值规则 Hook

所有 register/unregister 方法均为线程安全，并保持插入顺序。 Hook 按注册顺序被调用 — 最先注册的 Hook 最先执行。

IDietItemFoodEatHook

net.appleseed.appleseed.api.hook.IDietItemFoodEatHook

拦截和覆写物品食物进食检测逻辑。当玩家吃完任何食物物品时触发。

方法

shouldIntercept

boolean shouldIntercept(Player player, ItemStack stack)
决定此 Hook 是否接管指定食物物品的营养值计算。 当任一已注册的 Hook 返回 true 时，AppleSeed 将跳过默认的营养值查找， 仅使用 modifyNutritionGains 提供的值。
参数描述
player正在进食的玩家
stack正在被食用的食物 ItemStack
返回true 拦截并使用自定义营养值；false 使用默认逻辑

modifyNutritionGains

Map<String, Float> modifyNutritionGains(Player player, ItemStack stack, Map<String, Float> originalGains)
提供或修改营养值增益映射。无论 shouldIntercept 返回何值，此方法始终在默认营养值解析完成后 （或拦截后）被调用。
参数描述
player正在进食的玩家
stack正在被食用的食物 ItemStack
originalGains营养组名称 → 增益值 的映射（0.0 ~ 1.0）
返回修改后的营养增益映射

onAfterEat

default void onAfterEat(Player player, ItemStack stack)
在营养值已应用到玩家之后的回调。用于执行副作用（如发送消息、触发成就等）。
示例 — 自定义金苹果营养值
DietHookRegistry.registerItemFoodEatHook(new IDietItemFoodEatHook() {
    @Override
    public boolean shouldIntercept(Player player, ItemStack stack) {
        return stack.is(Items.GOLDEN_APPLE) || stack.is(Items.ENCHANTED_GOLDEN_APPLE);
    }

    @Override
    public Map<String, Float> modifyNutritionGains(
            Player player, ItemStack stack,
            Map<String, Float> originalGains) {
        Map<String, Float> custom = new HashMap<>();
        custom.put("fruits", 0.3f);
        custom.put("sugars", 0.1f);
        return custom;
    }

    @Override
    public void onAfterEat(Player player, ItemStack stack) {
        player.sendSystemMessage(
            Component.literal("你感觉更健康了！"));
    }
});

IDietBlockFoodEatHook

net.appleseed.appleseed.api.hook.IDietBlockFoodEatHook

拦截和覆写方块食物（如蛋糕）的进食检测逻辑。

方法

shouldProcessBlock

boolean shouldProcessBlock(Player player, Block block, BlockPos pos)
决定是否处理方块食物交互。在营养值查找之前调用。 所有已注册的 Hook 都必须返回 true（AND 逻辑）才能继续处理。
参数描述
player与方块交互的玩家
block被交互的方块
pos方块的位置
返回true 允许处理；false 取消处理

modifyNutritionGains

Map<String, Float> modifyNutritionGains(Player player, Block block, Map<String, Float> originalGains)
修改方块食物每次进食的营养值增益。原始增益值已经按口数分割（例如蛋糕有 7 口）。

onAfterEat

default void onAfterEat(Player player, Block block)
方块食物营养值应用后的回调。
示例 — 生日时蛋糕营养值翻倍
DietHookRegistry.registerBlockFoodEatHook(new IDietBlockFoodEatHook() {
    @Override
    public boolean shouldProcessBlock(Player player, Block block, BlockPos pos) {
        return true; // 始终允许
    }

    @Override
    public Map<String, Float> modifyNutritionGains(
            Player player, Block block,
            Map<String, Float> originalGains) {
        // 在玩家生日时双倍增益
        if (isBirthday(player)) {
            originalGains.replaceAll((k, v) -> v * 2.0f);
        }
        return originalGains;
    }
});

IDietRecipeFilterHook

net.appleseed.appleseed.api.hook.IDietRecipeFilterHook

控制哪些配方和物品参与自动营养值计算系统。

方法

isValidRecipeType

boolean isValidRecipeType(Recipe<?> recipe)
过滤在自动营养值计算中考虑的配方类型。 默认有效类型：CraftingRecipe、SmeltingRecipe、SmokingRecipe、 CampfireCookingRecipe、SimulateRecipe，以及 Create/Farmer's Delight 配方。 所有 Hook 必须返回 true（AND 逻辑）配方才会被包含。

shouldProcessItem

boolean shouldProcessItem(Item item)
过滤哪些食物物品被包含在自动计算集合中。 所有 Hook 必须返回 true（AND 逻辑）物品才会被处理。
示例 — 排除特定模组的配方
DietHookRegistry.registerRecipeFilterHook(new IDietRecipeFilterHook() {
    @Override
    public boolean isValidRecipeType(Recipe<?> recipe) {
        // 排除所有 Mekanism 配方
        return !recipe.getClass().getName().contains("mekanism");
    }

    @Override
    public boolean shouldProcessItem(Item item) {
        // 排除毒马铃薯
        return item != Items.POISONOUS_POTATO;
    }
});

IDietTooltipFilterHook

net.appleseed.appleseed.api.hook.IDietTooltipFilterHook

控制哪些物品显示营养值 Tooltip 以及显示什么内容。

方法

shouldShowTooltip

boolean shouldShowTooltip(ItemStack stack, Player player)
决定是否为此物品显示营养值 Tooltip。 所有 Hook 必须返回 true（AND 逻辑）Tooltip 才会显示。

modifyTooltipNutrition

Map<String, Float> modifyTooltipNutrition(ItemStack stack, Player player, Map<String, Float> originalNutritions)
修改 Tooltip 中显示的营养值。用于隐藏特定组别、调整显示值或添加自定义信息。
示例 — 隐藏未鉴定物品的 Tooltip
DietHookRegistry.registerTooltipFilterHook(new IDietTooltipFilterHook() {
    @Override
    public boolean shouldShowTooltip(ItemStack stack, Player player) {
        // 隐藏带有自定义 NBT 标签的物品的营养信息
        return !stack.hasTag() || !stack.getTag().contains("hidden_nutrition");
    }

    @Override
    public Map<String, Float> modifyTooltipNutrition(
            ItemStack stack, Player player,
            Map<String, Float> originalNutritions) {
        // 移除负数营养组别的显示
        originalNutritions.entrySet().removeIf(e -> e.getValue() < 0);
        return originalNutritions;
    }
});

IDietNutritionRuleHook

net.appleseed.appleseed.api.hook.IDietNutritionRuleHook

在最细粒度的层面覆写营养值的增加/设置/衰减规则。这些 Hook 在值实际写入玩家数据之前被调用。

方法

onBeforeAdd

float onBeforeAdd(Player player, String group, float value)
在营养值被增加（累加）之前调用。返回的值将替换原始值。 正向增益（进食）和负向增益（饥饿/攻击衰减）均会触发此方法。

onBeforeSet

float onBeforeSet(Player player, String group, float value)
在营养值被直接设置（覆盖）之前调用。返回的值将替换原始值。 最终值始终会被钳制在 [0.0, 1.0] 区间内。

onBeforeDecay

float onBeforeDecay(Player player, String group, float decay)
在衰减被应用之前调用（饥饿损失或受到伤害）。返回的衰减值将替换原始值。 返回 0 可完全阻止衰减。

onAfterChange

default void onAfterChange(Player player, String group, float oldValue, float newValue)
营养值变化后的回调。仅在值实际发生变化时调用（oldValue ≠ newValue）。
示例 — 老玩家更慢的营养衰减
DietHookRegistry.registerNutritionRuleHook(new IDietNutritionRuleHook() {
    @Override
    public float onBeforeAdd(Player player, String group, float value) {
        return value; // 不变
    }

    @Override
    public float onBeforeSet(Player player, String group, float value) {
        return value; // 不变
    }

    @Override
    public float onBeforeDecay(Player player, String group, float decay) {
        // 游戏时长超过 100 小时的玩家衰减速度减半
        if (player.getStats().getValue(Stats.PLAY_TIME) > 7200000) {
            return decay * 0.5f;
        }
        return decay;
    }

    @Override
    public void onAfterChange(Player player, String group,
                                   float oldValue, float newValue) {
        // 当某组营养值达到 100% 时通知玩家
        if (newValue >= 1.0f && oldValue < 1.0f) {
            player.sendSystemMessage(
                Component.literal("营养组 " + group + " 已达到最大值！"));
        }
    }
});

IDietResult

net.appleseed.appleseed.api.type.IDietResult   @FunctionalInterface

营养结果的不变表示 — 从营养组到浮点数值的映射。

常量

IDietResult EMPTY = Map::of

抽象方法

Map<IDietGroup, Float> get()

默认方法

default IDietResult merge(IDietResult other)
将另一个结果合并到当前结果中，重叠组的值会求和。返回新实例。
default IDietResult add(IDietGroup group, float value)
添加单个组-值对。返回新实例。
default IDietResult scale(float multiplier)
将所有值乘以指定倍数。返回新实例。
default boolean isEmpty()
如果没有营养条目则返回 true。
default float getValue(IDietGroup group)
返回指定组的值，若不存在则返回 0.0f。
示例 — 组合多个结果
IDietResult base = Map::of; // EMPTY
IDietResult withFruit = base.add(fruitGroup, 0.3f);
IDietResult combined = withFruit.merge(otherResult);
IDietResult doubled = combined.scale(2.0f);

if (!doubled.isEmpty()) {
    float fruitVal = doubled.getValue(fruitGroup);
}

执行流程

Hook API 如何集成到 AppleSeed 核心系统中：

物品食物进食

玩家吃完食物物品 | +--> DietHookRegistry.shouldInterceptItemFood() | 调用所有 IDietItemFoodEatHook.shouldIntercept() | 若任一返回 true → 跳过默认查找 | +--> 默认营养值查找（或使用拦截后的自定义增益） | +--> DietHookRegistry.modifyItemFoodGains() | 按顺序调用所有 IDietItemFoodEatHook.modifyNutritionGains() | +--> DietHookRegistry.processBeforeAdd() | 调用所有 IDietNutritionRuleHook.onBeforeAdd() | +--> DietData.addValue() → 钳制到 [0.0, 1.0] | +--> DietHookRegistry.processAfterChange() | 调用所有 IDietNutritionRuleHook.onAfterChange() | +--> DietHookRegistry.onAfterItemFoodEat() 调用所有 IDietItemFoodEatHook.onAfterEat()

营养衰减（饥饿 / 伤害）

饥饿损失或受到伤害 | +--> 计算基础衰减（饥饿：损失 * 0.005，伤害：0.001） | +--> DietHookRegistry.processBeforeDecay() | 调用所有 IDietNutritionRuleHook.onBeforeDecay() | 返回值 × 组衰减乘数 | +--> DietData.addValue(player, group, -decay) | +--> DietHookRegistry.processAfterChange() 调用所有 IDietNutritionRuleHook.onAfterChange()

方块食物进食

玩家右键点击食物方块 | +--> 检查 #appleseed:food_blocks 标签 | +--> DietHookRegistry.shouldProcessBlockFood() | 调用所有 IDietBlockFoodEatHook.shouldProcessBlock()（AND 逻辑） | +--> 查找方块营养数据，按口数分割 | +--> DietHookRegistry.modifyBlockFoodGains() | 调用所有 IDietBlockFoodEatHook.modifyNutritionGains() | +--> DietHookRegistry.processBeforeAdd() | +--> 对每个组调用 DietData.addValue() | +--> DietHookRegistry.processAfterChange() | +--> DietHookRegistry.onAfterBlockFoodEat()

Tooltip 显示

ItemTooltipEvent 触发 | +--> 检查食物属性或 food_blocks 标签 | +--> DietHookRegistry.shouldShowTooltip() | 调用所有 IDietTooltipFilterHook.shouldShowTooltip()（AND 逻辑） | +--> 获取营养数据（来自 SandwichCompat 或 FoodNutritionManager） | +--> DietHookRegistry.modifyTooltipNutrition() | 调用所有 IDietTooltipFilterHook.modifyTooltipNutrition() | +--> 渲染 Tooltip 行

自动计算

服务器数据包同步 / 重载 | +--> 从 RecipeManager 收集所有配方 | +--> DietHookRegistry.isValidRecipeType() | 调用所有 IDietRecipeFilterHook.isValidRecipeType()（AND 逻辑） | 附加硬编码类型检查（Crafting、Smelting 等） | +--> DietHookRegistry.shouldProcessItem() | 调用所有 IDietRecipeFilterHook.shouldProcessItem()（AND 逻辑） | +--> 对每个食物物品进行递归配方分析 | +--> 保存计算结果到配置文件
