Overview

AppleSeed provides a comprehensive Hook API that allows other mods to intercept and override core nutrition system behaviors at runtime. Combined with the Type API for data modeling, external mods can fully customize food detection, recipe filtering, tooltip rendering, and nutrition value rules.

All API classes reside under the net.appleseed.appleseed.api package:

  • api.hook — Hook interfaces + DietHookRegistry (register/unregister/call)
  • api.type — Data type interfaces (IDietGroup, IDietResult, etc.)
  • api.util — Utility records (DietColor)
Registration Timing: Hooks should be registered during mod initialization (e.g., in your @Mod constructor or on the FMLCommonSetupEvent). Hooks take effect immediately and persist until explicitly unregistered.

Quick Start

Register a hook in your mod's constructor:

Example — Minimal Hook Registration
@Mod("yourmodid")
public class YourMod {
    public YourMod() {
        DietHookRegistry.registerItemFoodEatHook(new IDietItemFoodEatHook() {
            @Override
            public boolean shouldIntercept(Player player, ItemStack stack) {
                return stack.is(Items.GOLDEN_APPLE);
            }

            @Override
            public Map<String, Float> modifyNutritionGains(
                    Player player, ItemStack stack,
                    Map<String, Float> originalGains) {
                originalGains.put("fruits", 0.5f);
                return originalGains;
            }
        });
    }
}

DietHookRegistry

net.appleseed.appleseed.api.hook.DietHookRegistry

Central registry for all Hook interfaces. Provides static register/unregister methods for each Hook type, and internal static methods that the AppleSeed core calls to invoke all registered hooks in order.

MethodDescription
registerItemFoodEatHook(IDietItemFoodEatHook)Register an item food eat hook
unregisterItemFoodEatHook(IDietItemFoodEatHook)Unregister an item food eat hook
registerBlockFoodEatHook(IDietBlockFoodEatHook)Register a block food eat hook
unregisterBlockFoodEatHook(IDietBlockFoodEatHook)Unregister a block food eat hook
registerRecipeFilterHook(IDietRecipeFilterHook)Register a recipe filter hook
unregisterRecipeFilterHook(IDietRecipeFilterHook)Unregister a recipe filter hook
registerTooltipFilterHook(IDietTooltipFilterHook)Register a tooltip filter hook
unregisterTooltipFilterHook(IDietTooltipFilterHook)Unregister a tooltip filter hook
registerNutritionRuleHook(IDietNutritionRuleHook)Register a nutrition rule hook
unregisterNutritionRuleHook(IDietNutritionRuleHook)Unregister a nutrition rule hook

All register/unregister methods are thread-safe and maintain insertion order. Hooks are invoked in registration order — the first registered hook runs first.

IDietItemFoodEatHook

net.appleseed.appleseed.api.hook.IDietItemFoodEatHook

Intercept and override item food eating detection logic. Called when a player finishes eating any food item.

Methods

shouldIntercept

boolean shouldIntercept(Player player, ItemStack stack)
Determines whether this hook should take over nutrition calculation for the given food item. When any registered hook returns true, AppleSeed skips its default nutrition lookup and uses modifyNutritionGains exclusively.
ParameterDescription
playerThe player who is eating
stackThe food ItemStack being consumed
Returnstrue to intercept and use custom nutrition; false to use default logic

modifyNutritionGains

Map<String, Float> modifyNutritionGains(Player player, ItemStack stack, Map<String, Float> originalGains)
Provides or modifies the nutrition gain map. Called regardless of whether shouldIntercept returned true — it is always invoked after the default nutrition values are resolved (or after interception).
ParameterDescription
playerThe player who is eating
stackThe food ItemStack being consumed
originalGainsMap of nutrition group name → gain value (0.0 ~ 1.0)
ReturnsModified nutrition gain map

onAfterEat

default void onAfterEat(Player player, ItemStack stack)
Callback invoked after nutrition values have been applied to the player. Use for side effects (e.g., sending messages, triggering achievements).
Example — Custom Golden Apple Nutrition
DietHookRegistry.registerItemFoodEatHook(new IDietItemFoodEatHook() {
    @Override
    public boolean shouldIntercept(Player player, ItemStack stack) {
        return stack.is(Items.GOLDEN_APPLE) || stack.is(Items.ENCHANTED_GOLDEN_APPLE);
    }

    @Override
    public Map<String, Float> modifyNutritionGains(
            Player player, ItemStack stack,
            Map<String, Float> originalGains) {
        Map<String, Float> custom = new HashMap<>();
        custom.put("fruits", 0.3f);
        custom.put("sugars", 0.1f);
        return custom;
    }

    @Override
    public void onAfterEat(Player player, ItemStack stack) {
        player.sendSystemMessage(
            Component.literal("You feel healthier!"));
    }
});

IDietBlockFoodEatHook

net.appleseed.appleseed.api.hook.IDietBlockFoodEatHook

Intercept and override block food (e.g., cake) eating detection logic.

Methods

shouldProcessBlock

boolean shouldProcessBlock(Player player, Block block, BlockPos pos)
Determines whether the block food interaction should be processed. Called before nutrition lookup. All registered hooks must return true for processing to continue (AND logic).
ParameterDescription
playerThe player interacting with the block
blockThe block being interacted with
posPosition of the block
Returnstrue to allow processing; false to cancel

modifyNutritionGains

Map<String, Float> modifyNutritionGains(Player player, Block block, Map<String, Float> originalGains)
Modifies the per-bite nutrition gains for block food. The original gains are already divided by the number of bites (e.g., cake has 7 bites).

onAfterEat

default void onAfterEat(Player player, Block block)
Callback after block food nutrition has been applied.
Example — Double Cake Nutrition on Birthdays
DietHookRegistry.registerBlockFoodEatHook(new IDietBlockFoodEatHook() {
    @Override
    public boolean shouldProcessBlock(Player player, Block block, BlockPos pos) {
        return true; // always allow
    }

    @Override
    public Map<String, Float> modifyNutritionGains(
            Player player, Block block,
            Map<String, Float> originalGains) {
        // Double gains on player's birthday
        if (isBirthday(player)) {
            originalGains.replaceAll((k, v) -> v * 2.0f);
        }
        return originalGains;
    }
});

IDietRecipeFilterHook

net.appleseed.appleseed.api.hook.IDietRecipeFilterHook

Control which recipes and items participate in the automatic nutrition calculation system.

Methods

isValidRecipeType

boolean isValidRecipeType(Recipe<?> recipe)
Filters which recipe types are considered during automatic nutrition calculation. Default valid types: CraftingRecipe, SmeltingRecipe, SmokingRecipe, CampfireCookingRecipe, SimulateRecipe, and Create/Farmer's Delight recipes. All hooks must return true (AND logic) for a recipe to be included.

shouldProcessItem

boolean shouldProcessItem(Item item)
Filters which food items are included in the automatic calculation set. All hooks must return true (AND logic) for an item to be processed.
Example — Exclude Specific Mod's Recipes
DietHookRegistry.registerRecipeFilterHook(new IDietRecipeFilterHook() {
    @Override
    public boolean isValidRecipeType(Recipe<?> recipe) {
        // Exclude all Mekanism recipes from auto-calculation
        return !recipe.getClass().getName().contains("mekanism");
    }

    @Override
    public boolean shouldProcessItem(Item item) {
        // Exclude poisonous potatoes from calculation
        return item != Items.POISONOUS_POTATO;
    }
});

IDietTooltipFilterHook

net.appleseed.appleseed.api.hook.IDietTooltipFilterHook

Control which items display nutrition tooltips and what values they show.

Methods

shouldShowTooltip

boolean shouldShowTooltip(ItemStack stack, Player player)
Determines whether the nutrition tooltip should be displayed for this item. All hooks must return true (AND logic) for the tooltip to appear.

modifyTooltipNutrition

Map<String, Float> modifyTooltipNutrition(ItemStack stack, Player player, Map<String, Float> originalNutritions)
Modifies the nutrition values shown in the tooltip. Use this to hide certain groups, adjust display values, or add custom information.
Example — Hide Tooltip for Unidentified Items
DietHookRegistry.registerTooltipFilterHook(new IDietTooltipFilterHook() {
    @Override
    public boolean shouldShowTooltip(ItemStack stack, Player player) {
        // Hide nutrition info for items with custom NBT
        return !stack.hasTag() || !stack.getTag().contains("hidden_nutrition");
    }

    @Override
    public Map<String, Float> modifyTooltipNutrition(
            ItemStack stack, Player player,
            Map<String, Float> originalNutritions) {
        // Remove negative nutrition groups from display
        originalNutritions.entrySet().removeIf(e -> e.getValue() < 0);
        return originalNutritions;
    }
});

IDietNutritionRuleHook

net.appleseed.appleseed.api.hook.IDietNutritionRuleHook

Override nutrition value add/set/decay rules at the most granular level. These hooks are called before the value is actually written to the player's data.

Methods

onBeforeAdd

float onBeforeAdd(Player player, String group, float value)
Called before a nutrition value is added (incremented). The returned value replaces the original. This is called for both positive gains (eating) and negative gains (decay via hunger/attack).

onBeforeSet

float onBeforeSet(Player player, String group, float value)
Called before a nutrition value is directly set (overwritten). The returned value replaces the original. The final value is always clamped to [0.0, 1.0].

onBeforeDecay

float onBeforeDecay(Player player, String group, float decay)
Called before decay is applied (hunger loss or damage taken). The returned decay value replaces the original. Return 0 to prevent decay entirely.

onAfterChange

default void onAfterChange(Player player, String group, float oldValue, float newValue)
Callback after a nutrition value has changed. Only called when the value actually changed (oldValue ≠ newValue).
Example — Slow Decay for Veteran Players
DietHookRegistry.registerNutritionRuleHook(new IDietNutritionRuleHook() {
    @Override
    public float onBeforeAdd(Player player, String group, float value) {
        return value; // no change
    }

    @Override
    public float onBeforeSet(Player player, String group, float value) {
        return value; // no change
    }

    @Override
    public float onBeforeDecay(Player player, String group, float decay) {
        // Players with >100 hours playtime get 50% slower decay
        if (player.getStats().getValue(Stats.PLAY_TIME) > 7200000) {
            return decay * 0.5f;
        }
        return decay;
    }

    @Override
    public void onAfterChange(Player player, String group,
                                   float oldValue, float newValue) {
        // Notify when a group reaches 100%
        if (newValue >= 1.0f && oldValue < 1.0f) {
            player.sendSystemMessage(
                Component.literal("Nutrition group " + group + " is maxed out!"));
        }
    }
});

IDietResult

net.appleseed.appleseed.api.type.IDietResult   @FunctionalInterface

Immutable representation of a nutrition result — a mapping from nutrition groups to float values.

Constants

IDietResult EMPTY = Map::of

Abstract Method

Map<IDietGroup, Float> get()

Default Methods

default IDietResult merge(IDietResult other)
Merges another result into this one, summing values for overlapping groups. Returns a new instance.
default IDietResult add(IDietGroup group, float value)
Adds a single group-value pair. Returns a new instance.
default IDietResult scale(float multiplier)
Multiplies all values by the given factor. Returns a new instance.
default boolean isEmpty()
Returns true if there are no nutrition entries.
default float getValue(IDietGroup group)
Returns the value for a specific group, or 0.0f if absent.
Example — Composing Results
IDietResult base = Map::of; // EMPTY
IDietResult withFruit = base.add(fruitGroup, 0.3f);
IDietResult combined = withFruit.merge(otherResult);
IDietResult doubled = combined.scale(2.0f);

if (!doubled.isEmpty()) {
    float fruitVal = doubled.getValue(fruitGroup);
}

Execution Flow

How the Hook API integrates into AppleSeed's core systems:

Item Food Eating

Player eats food item | +--> DietHookRegistry.shouldInterceptItemFood() | All IDietItemFoodEatHook.shouldIntercept() called | If any returns true → skip default lookup | +--> Default nutrition lookup (or use intercepted custom gains) | +--> DietHookRegistry.modifyItemFoodGains() | All IDietItemFoodEatHook.modifyNutritionGains() called in order | +--> DietHookRegistry.processBeforeAdd() | All IDietNutritionRuleHook.onBeforeAdd() called | +--> DietData.addValue() → clamped to [0.0, 1.0] | +--> DietHookRegistry.processAfterChange() | All IDietNutritionRuleHook.onAfterChange() called | +--> DietHookRegistry.onAfterItemFoodEat() All IDietItemFoodEatHook.onAfterEat() called

Nutrition Decay (Hunger / Damage)

Hunger loss or damage taken | +--> Calculate base decay (hunger: lost * 0.005, damage: 0.001) | +--> DietHookRegistry.processBeforeDecay() | All IDietNutritionRuleHook.onBeforeDecay() called | Returned value × group decay multiplier | +--> DietData.addValue(player, group, -decay) | +--> DietHookRegistry.processAfterChange() All IDietNutritionRuleHook.onAfterChange() called

Block Food Eating

Player right-clicks food block | +--> Check #appleseed:food_blocks tag | +--> DietHookRegistry.shouldProcessBlockFood() | All IDietBlockFoodEatHook.shouldProcessBlock() called (AND logic) | +--> Lookup block nutrition data, divide by bites | +--> DietHookRegistry.modifyBlockFoodGains() | All IDietBlockFoodEatHook.modifyNutritionGains() called | +--> DietHookRegistry.processBeforeAdd() | +--> DietData.addValue() for each group | +--> DietHookRegistry.processAfterChange() | +--> DietHookRegistry.onAfterBlockFoodEat()

Tooltip Display

ItemTooltipEvent fires | +--> Check food properties or food_blocks tag | +--> DietHookRegistry.shouldShowTooltip() | All IDietTooltipFilterHook.shouldShowTooltip() called (AND logic) | +--> Get nutrition data (from SandwichCompat or FoodNutritionManager) | +--> DietHookRegistry.modifyTooltipNutrition() | All IDietTooltipFilterHook.modifyTooltipNutrition() called | +--> Render tooltip lines

Auto Calculation

Server datapack sync / reload | +--> Collect all recipes from RecipeManager | +--> DietHookRegistry.isValidRecipeType() | All IDietRecipeFilterHook.isValidRecipeType() called (AND logic) | Additional hardcoded type checks (Crafting, Smelting, etc.) | +--> DietHookRegistry.shouldProcessItem() | All IDietRecipeFilterHook.shouldProcessItem() called (AND logic) | +--> Recursive recipe analysis for each food item | +--> Save calculated nutrition to config
